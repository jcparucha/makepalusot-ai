# MakePalusot AI

A _witty_ AI-powered Excuse Generator.

Para kahit anong excuses mo, sa work, school, or kahit sa bahay, makakalusot yan 🤞

## PURPOSE

Convert a user's rough excuse into a more polished message using AI.

Examples:

- Formal
- Friendly
- Casual

The goal is to help users communicate their situation more clearly and appropriately for the intended audience.
